# MCP Test

Project scaffold for Next.js 14+ marketing/customer platform.

## Structure

* Modular Next.js app router with RESTful API in /app/api/
* SQLite data models and migrations under /lib/
* Integration connectors for Toast, Resy, Mailchimp/Brevo, and AI
* Reusable UI in /components
* Dashboard and analytics
* Tests included for all critical logic
